FAQ

Pricing, language, storage, and troubleshooting — answered.

How much does it cost?Pricing
Quarterly: $9.9. Yearly: $36. See the pricing page. Pricing
Is it bilingual (EN/中文)?Language
Yes. Switch languages in the top bar. Default is English.
Is my data stored locally?Storage
By default, prompts are stored locally in your browser. See the privacy policy for details. Privacy
Does it work on my site?Compatibility
Compatibility depends on the site and is continuously improved.
Nothing shows up after install — what to do?Troubleshooting
Try: restart Chrome, ensure the extension is enabled, pin it to the toolbar, and check enterprise policies.
Why can’t I find my saved prompt?Storage
If you use multiple devices, make sure you’re using the same browser profile. Local data does not automatically sync across devices unless you build a sync feature.
