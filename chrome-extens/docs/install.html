Install & quick start

Install in 1 minute. Save and paste prompts by right‑click.

Install

Open the Chrome Web Store listing

Click “Add to Chrome”

Pin the extension (optional)

Open listing

First use

Select text → right‑click → Save as Prompt

AI auto categorizes and tags it

In any input: right‑click → Paste recent or pinned prompt

Keep your daily prompts pinned

Demo walkthrough

Use real screenshots and GIFs to show what users will see after installation.

1. Save from the page 1. 从页面中保存

Select useful text, save it as a prompt, and let AI organize it automatically. 选中有价值的文本后直接保存为 Prompt，并交给 AI 自动整理分类。

2. Open by right‑click 2. 右键呼出使用

Inside an AI chat box, open the menu by right‑click and quickly copy or insert a saved prompt. 在 AI 对话输入框里右键呼出菜单，快速复制或插入已经保存的 Prompt。

3. Manage in dashboard 3. 在后台统一管理

Review categories, tags, and prompt actions in a dedicated dashboard view. 在独立后台中统一查看分类、标签与 Prompt 操作，形成可维护的资产库。

4. Clean up outdated prompts 4. 清理过时 Prompt

Remove old entries whenever necessary to keep the library relevant and easy to use. 随时删除过期内容，让提示词库保持轻量、相关、易于调用。
