Save prompt by right‑clickSave

Users can save a prompt directly from the current page, then let AI organize it into the right category and tags. 用户可以直接在当前页面右键保存 Prompt，随后由 AI 自动归类并补全标签。

Open and copy from context menuRight Click

When writing in tools like Gemini, users can right‑click to open the prompt menu and quickly copy or insert a saved prompt. 在 Gemini 等工具里输入时，用户可以右键呼出 Prompt 菜单，快速复制或插入已保存提示词。

Delete and keep the library cleanManage

Prompt assets are easy to maintain. Users can delete outdated entries and keep the library focused on what still works. Prompt 资产可以持续维护。用户能删除过时条目，让提示词库始终保持干净、可复用。
